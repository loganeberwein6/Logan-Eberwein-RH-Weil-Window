## Candidate 1: Explicit single-orbit arithmetic suspension

### 1. CONSTRUCTION

Let

\[
X_1=\bigsqcup_{p\ \mathrm{prime}}\mathbb R/(\log p)\mathbb Z.
\]

The flow is translation on each circle:

\[
\phi_t([x]_{\log p})=[x+t]_{\log p}.
\]

Use the Hilbert cohomology/function space

\[
\mathcal H_1=
\bigoplus_{p\ \mathrm{prime}}
L^2(\mathbb R/(\log p)\mathbb Z),
\]

with the direct-sum unitary flow \(U_t\). For a Schwartz function \(f\), define

\[
U(f)=\int_{\mathbb R}f(t)U_t\,dt
\]

blockwise by Bochner integration.

There is exactly one primitive circle for each prime. Its iterates supply the lengths \(m\log p\). No zeta-zero locations are used.

### 2. TEST (a): ORBIT LENGTHS

For \(p=2\):

- \(m=1\): the unique primitive orbit has length \(\log 2\);
- \(m=2\): its second iterate has length \(2\log 2\).

For \(p=3\):

- \(m=1\): the unique primitive orbit has length \(\log 3\);
- \(m=2\): its second iterate has length \(2\log 3\).

There are no separate primitive circles indexed by \(m\), so no duplicate primitive contribution is introduced. By unique factorization and the \(\mathbb Q\)-linear independence of the \(\log p\), each pair \((p,m)\) gives exactly one iterate contribution. Gate 1(a) passes.

### 3. TEST (b): TRACE-CLASS BEHAVIOR

On the circle of length \(L=\log p\), the flow generator has eigenvalues

\[
\frac{2\pi k}{L},\qquad k\in\mathbb Z.
\]

Hence the smeared block has eigenvalues

\[
\widehat f\left(\frac{2\pi k}{L}\right),
\]

and its trace, when defined, is

\[
\operatorname{tr}U_p(f)
=
\sum_{k\in\mathbb Z}
\widehat f\left(\frac{2\pi k}{\log p}\right).
\]

Choose the fixed Schwartz function

\[
f(t)=e^{-t^2}.
\]

Its Fourier transform is strictly positive, so every block trace satisfies

\[
\operatorname{tr}U_p(f)\ge\widehat f(0)>0.
\]

Therefore

\[
\operatorname{tr}U(f)
=
\sum_{p\ \mathrm{prime}}\operatorname{tr}U_p(f)
\ge
\widehat f(0)\sum_{p\ \mathrm{prime}}1
=
+\infty.
\]

Thus \(U(f)\) is not trace class. No cutoff subtraction was used; the divergence is the direct positive sum over primitive prime-orbit blocks. Gate 1(b) fails.

### 4. TEST (c): INPUTS

Inputs are:

- the set of ordinary primes;
- the primitive orbit length \(\log p\);
- integer iteration of each primitive orbit;
- the standard translation flow on circles;
- the fixed Schwartz test function \(f(t)=e^{-t^2}\).

No zeta-zero locations, zero ordinates, or RH assumptions are used. Gate 1(c) passes.

### 5. VERDICT

**FAIL(b).**

The model has exactly one primitive orbit per prime and exactly one iterate contribution for each \((p,m)\), but its natural direct-sum cohomology is too large: one fixed positive Schwartz smearing has infinite trace.

### 6. FAILURE CLASS

**Infinite orbit multiplicity / trace divergence.**

Mechanism: even with the correct orbit count—one primitive orbit per prime—the direct sum over infinitely many primes produces infinitely many positive trace contributions. This is an explicit instance of the known “no trace-class cohomology” obstruction, distinct from packet multiplicity.

### 7. CONSTRAINT FOR THE NEXT CANDIDATE

The next candidate must retain one primitive orbit per prime while replacing the direct-sum \(L^2\) cohomology by an explicitly weighted or cancellative cohomology on which every Schwartz smearing is trace class. Any weight or quotient must be explicitly defined and may not use zero locations.



## Candidate 2: Prime-weighted direct-sum cohomology

### 1. CONSTRUCTION

Keep the same flow space as Candidate 1,

\[
X_2=\bigsqcup_{p\ \mathrm{prime}}\mathbb R/(\log p)\mathbb Z,
\]

but define the weighted Hilbert space

\[
\mathcal H_2=
\left\{(f_p)_p:
\sum_{p\ \mathrm{prime}}p^{-2}\|f_p\|_{L^2(\mathbb R/(\log p)\mathbb Z)}^2<\infty\right\}.
\]

The flow remains blockwise translation:

\[
(U_t f)_p(x)=f_p(x-t).
\]

The weight \(p^{-2}\) is explicit, positive, and uses no zero data. The intended repair is that large-prime blocks might become trace-summable.

### 2. TEST (a): ORBIT LENGTHS

The orbit space is unchanged.

For \(p=2\):

- \(m=1\): one primitive orbit of length \(\log 2\);
- \(m=2\): its second iterate has length \(2\log 2\).

For \(p=3\):

- \(m=1\): one primitive orbit of length \(\log 3\);
- \(m=2\): its second iterate has length \(2\log 3\).

The weights do not change the flow or orbit multiplicities. Gate 1(a) passes.

### 3. TEST (b): TRACE-CLASS BEHAVIOR

Define

\[
J:\mathcal H_2\to\mathcal H_1,
\qquad
J((f_p)_p)=(p^{-1}f_p)_p.
\]

Then \(J\) is unitary because

\[
\|Jf\|_{\mathcal H_1}^2
=
\sum_p p^{-2}\|f_p\|^2
=
\|f\|_{\mathcal H_2}^2.
\]

The flow and every smeared operator are conjugate:

\[
J U_t^{(2)}J^{-1}=U_t^{(1)},
\qquad
J U^{(2)}(f)J^{-1}=U^{(1)}(f).
\]

Therefore trace class is unchanged by the weighting. For the same fixed Gaussian \(f(t)=e^{-t^2}\),

\[
\operatorname{tr}U^{(2)}(f)
=
\operatorname{tr}U^{(1)}(f)
=
+\infty.
\]

The weight changes the coordinate norm but not the operator's trace-class property. Gate 1(b) fails.

### 4. TEST (c): INPUTS

Inputs are:

- ordinary primes;
- the primitive lengths \(\log p\);
- the explicit weights \(p^{-2}\);
- circle translation;
- the fixed Gaussian Schwartz function.

No zeta-zero locations or RH assumptions are used. Gate 1(c) passes.

### 5. VERDICT

**FAIL(b).**

A scalar reweighting of the direct-sum Hilbert norm is a unitary change of representation. It cannot cure the divergent positive trace.

### 6. FAILURE CLASS

**Infinite orbit multiplicity / trace divergence.**

This repeats Candidate 1's mechanism, not because the candidate is identical, but because any positive blockwise Hilbert reweighting is unitarily equivalent to the same direct sum. The failure is therefore structural for this class.

### 7. CONSTRAINT FOR THE NEXT CANDIDATE

The next candidate must change the cohomological operator itself—by a specified quotient, cancellation, or nontrivial differential—not merely rescale the norms of independent orbit blocks. It must preserve the arithmetic trace coefficients while making the smeared operator trace class.



## Candidate 3: Reduced cohomology removing the constant mode

### 1. CONSTRUCTION

Use the same orbit space and flow, but replace each circle's cohomology by its mean-zero subspace:

\[
\mathcal H_3=
\bigoplus_{p\ \mathrm{prime}}L^2_0(\mathbb R/(\log p)\mathbb Z),
\]

where

\[
L^2_0(\mathbb R/(\log p)\mathbb Z)
=
\left\{g:\int_0^{\log p}g(x)\,dx=0\right\}.
\]

The flow is translation, which preserves the mean-zero condition. This is an explicit quotient/removal of the constant Fourier mode, not a norm reweighting.

### 2. TEST (a): ORBIT LENGTHS

The underlying flow space is unchanged.

For \(p=2\):

- \(m=1\): one primitive orbit of length \(\log 2\);
- \(m=2\): its second iterate has length \(2\log 2\).

For \(p=3\):

- \(m=1\): one primitive orbit of length \(\log 3\);
- \(m=2\): its second iterate has length \(2\log 3\).

The quotient changes cohomology, not the orbit geometry. Gate 1(a) passes.

### 3. TEST (b): TRACE-CLASS BEHAVIOR

The Fourier modes on the \(p\)-circle are now \(k\in\mathbb Z\setminus\{0\}\). For a Schwartz function \(f\), the block trace is

\[
\operatorname{tr}U_{p,0}(f)
=
\sum_{k\ne0}
\widehat f\left(\frac{2\pi k}{\log p}\right).
\]

Choose \(f(t)=e^{-t^2}\), so \(\widehat f\) is strictly positive and continuous at zero. As \(p\to\infty\),

\[
\frac{2\pi}{\log p}\to0.
\]

Hence for all sufficiently large primes,

\[
\widehat f\left(\frac{2\pi}{\log p}\right)
\ge \frac12\widehat f(0),
\]

and therefore

\[
\operatorname{tr}U_{p,0}(f)
\ge
2\widehat f\left(\frac{2\pi}{\log p}\right)
\ge
\widehat f(0).
\]

Summing over sufficiently large primes gives

\[
\operatorname{tr}U_3(f)=+\infty.
\]

Thus removing the constant mode does not make the smeared direct sum trace class. Gate 1(b) fails.

### 4. TEST (c): INPUTS

Inputs are:

- ordinary primes;
- one primitive circle of length \(\log p\) per prime;
- the mean-zero quotient;
- circle translation;
- the fixed Gaussian Schwartz function.

No zeta-zero locations or RH assumptions are used. Gate 1(c) passes.

### 5. VERDICT

**FAIL(b).**

A finite-dimensional-looking cohomological cancellation at each orbit is insufficient. The first nonzero Fourier modes approach frequency zero as \(p\to\infty\), leaving a uniformly positive trace contribution from infinitely many primes.

### 6. FAILURE CLASS

**Infinite orbit multiplicity / trace divergence.**

This is the third occurrence. It is stronger than the previous two examples: neither positive Hilbert reweighting nor removal of the zero Fourier mode cures the divergence.

### 7. CONSTRAINT FOR THE NEXT CANDIDATE

The next candidate must impose cancellation or spectral suppression that acts uniformly on the low-frequency modes of large-\(p\) circles while preserving the full arithmetic orbit contribution. A finite-dimensional quotient per orbit is insufficient.




## Candidate 4: Prime-dependent high-frequency cohomology

### 1. CONSTRUCTION

For each prime \(p\), let \(L_p=\log p\) and define

\[
K_p=\left\lceil L_p^2\right\rceil.
\]

Keep the circle \(\mathbb R/L_p\mathbb Z\), but use the invariant Fourier subspace

\[
\mathcal H_{4,p}
=
\overline{\operatorname{span}}
\left\{e^{2\pi ikx/L_p}: |k|\ge K_p\right\}.
\]

Set

\[
\mathcal H_4=\bigoplus_{p\ \mathrm{prime}}\mathcal H_{4,p},
\]

with the usual translation flow. This explicitly suppresses all low frequencies whose flow-generator magnitude is below approximately \(2\pi\log p\). It uses only \(p\) and no zero data.

### 2. TEST (a): ORBIT LENGTHS AND CONTRIBUTION

The underlying circles still have primitive lengths \(\log p\), and their iterates still have lengths \(m\log p\). Thus the geometric orbit-length part passes.

However, the trace on a \(p\)-block is now

\[
\operatorname{tr}U_{4,p}(f)
=
\sum_{|k|\ge K_p}
\widehat f\left(\frac{2\pi k}{\log p}\right).
\]

The standard Lefschetz contribution of the primitive orbit has been spectrally filtered: the block no longer supplies the unmodified one-orbit contribution. The exact arithmetic weight is replaced by the \(p\)-dependent filtered sum. Therefore Gate 1(a), interpreted as the full arithmetic contribution and not only the geometric length, fails.

### 3. TEST (b): TRACE-CLASS BEHAVIOR

For \(f(t)=e^{-t^2}\),

\[
\widehat f(\omega)=\sqrt{\pi}\,e^{-\omega^2/4}.
\]

For \(|k|\ge K_p\),

\[
\left|\frac{2\pi k}{\log p}\right|
\ge
2\pi\log p.
\]

Hence

\[
0\le \operatorname{tr}U_{4,p}(f)
\le
2\sqrt{\pi}
\sum_{k\ge K_p}
e^{-\pi^2 k^2/(\log p)^2}.
\]

The first term is bounded by

\[
2\sqrt{\pi}\,
e^{-\pi^2(\log p)^2},
\]

up to a harmless convergent tail factor. Since

\[
e^{-\pi^2(\log p)^2}
=
p^{-\pi^2\log p},
\]

the sum over primes converges absolutely. The individual blocks are trace class and their direct sum is trace class for this fixed Gaussian. Gate 1(b) passes for the test.

### 4. TEST (c): INPUTS

Inputs are:

- ordinary primes;
- primitive circle lengths \(\log p\);
- the explicit cutoff \(K_p=\lceil(\log p)^2\rceil\);
- translation on each circle;
- the fixed Gaussian Schwartz function.

No zeta-zero locations or zero ordinates are used. Gate 1(c) passes.

### 5. VERDICT

**FAIL(a).**

This candidate achieves trace summability only by deleting the low-frequency part of each orbit's cohomology. The resulting trace no longer gives exactly one unfiltered arithmetic contribution for each prime and iterate. It is a spectral cutoff disguised as cohomological structure.

### 6. FAILURE CLASS

**Spectral filtering changes orbit coefficients.**

Mechanism: suppressing enough low modes can force trace class, but the same suppression changes the Lefschetz weight of each orbit. This is a new failure class, distinct from unavoidable divergence in the unfiltered direct sum.

### 7. CONSTRAINT FOR THE NEXT CANDIDATE

The next candidate must achieve trace-class summability through a genuine differential or exact cohomological cancellation whose Lefschetz trace remains the unfiltered orbit contribution. A mode cutoff depending on \(p\) is not admissible.






## Candidate 5: Two-term de Rham cancellation on each prime circle

### 1. CONSTRUCTION

For each prime \(p\), let \(C_p=\mathbb R/(\log p)\mathbb Z\). Use the two-term periodic de Rham complex

\[
0\longrightarrow L^2(C_p)
\xrightarrow{\,d/dx\,}
L^2(C_p)\,dx
\longrightarrow0.
\]

The flow translates functions and one-forms simultaneously. Set

\[
\mathcal C_5^\bullet
=
\bigoplus_{p\ \mathrm{prime}}
\left(L^2(C_p)\to L^2(C_p)\,dx\right).
\]

The proposed trace is the supertrace, hoping that the degree-zero and degree-one spectra cancel exactly.

### 2. TEST (a): ORBIT LENGTHS AND CONTRIBUTION

The underlying flow has one primitive orbit of length \(\log p\) for each prime. Its iterates have lengths \(m\log p\). Thus the geometric orbit lengths pass.

However, the two de Rham degrees carry identical translation spectra. For every Schwartz \(f\),

\[
\operatorname{str}U_p(f)
=
\operatorname{tr}U_p^{(0)}(f)
-
\operatorname{tr}U_p^{(1)}(f)
=
0.
\]

Therefore the cancellation removes the entire orbit contribution instead of producing one arithmetic term per \((p,m)\). Gate 1(a) fails for the supertrace.

### 3. TEST (b): TRACE-CLASS BEHAVIOR

If the ordinary trace on the direct sum is used, it is twice the divergent trace of Candidate 1 and is not trace class.

If the supertrace is used, it is identically zero on every block and therefore trivially summable, but that is precisely the failure of Gate 1(a). No honest nonzero Lefschetz trace has been obtained.

### 4. TEST (c): INPUTS

Inputs are:

- ordinary primes;
- the circles of primitive lengths \(\log p\);
- the standard de Rham differential \(d/dx\);
- translation on functions and one-forms;
- no zero locations.

Gate 1(c) passes.

### 5. VERDICT

**FAIL(a).**

Exact de Rham cancellation can remove the divergent trace only by canceling the arithmetic orbit term itself. It does not produce the required one-contribution-per-prime-and-iterate formula.

### 6. FAILURE CLASS

**Exact cohomological cancellation erases the orbit contribution.**

Mechanism: when two cohomological degrees have identical flow spectra, the supertrace is zero. This is distinct from spectral filtering: no modes are deleted, but the required trace is canceled.

### 7. CONSTRAINT FOR THE NEXT CANDIDATE

The next candidate must use a nontrivial differential or complex whose alternating trace cancels only the divergent continuous/background part while leaving exactly one arithmetic orbit contribution. A symmetric copy of the same orbit spectrum is insufficient.



## Candidate 6: Unpaired index summand over the de Rham cancellation

### 1. CONSTRUCTION

For each prime p, let C_p = R/(log p)Z. Define a two-term complex 0 -> C_p^0 -> C_p^1 -> 0, with C_p^0 = L^2(C_p), C_p^1 = L^2(C_p) direct-sum C, differential d_p(f) = (f,0). The flow is translation on both L^2(C_p) copies and the identity on the additional C summand. Take the direct sum over all primes and use the supertrace of the smeared flow. The construction is explicit, uses no zero locations, and leaves one unpaired index mode per prime.

### 2. TEST (a): ORBIT LENGTHS AND CONTRIBUTION

For p = 2, the unique primitive orbit has length log 2 and its second iterate has length 2 log 2. For p = 3, the unique primitive orbit has length log 3 and its second iterate has length 2 log 3. Geometrically there is exactly one primitive orbit per prime and one iterate for each m. The L^2 spectra cancel in the supertrace, while the unpaired C summand contributes one scalar term per prime. Thus the construction has the correct orbit indexing but its residual contribution is a prime-indexed scalar background rather than a trace-class arithmetic realization. Gate 1(a) fails as a full Lefschetz realization.

### 3. TEST (b): TRACE-CLASS BEHAVIOR

For a Schwartz function f, the two L^2 spectra cancel formally in the supertrace and the unpaired one-dimensional summand contributes hat f(0) on every prime block. For the fixed Gaussian f(t) = exp(-t^2), hat f(0) = sqrt(pi) > 0. Therefore str U_6(f) = sum over primes of hat f(0) = +infinity. The residual index contribution is not trace class. The exact cancellation has removed the oscillatory circle spectrum but has left a nonzero contribution on infinitely many prime blocks. Gate 1(b) fails.

### 4. TEST (c): INPUTS

Inputs are the ordinary primes, the primitive lengths log p, the explicit differential d_p(f) = (f,0), translation on the circles, the identity action on the extra scalar summand, and the fixed Gaussian test function. No zeta-zero locations or zero ordinates are used. Gate 1(c) passes.

### 5. VERDICT

**FAIL(b).**

The unpaired index repairs Candidate 5 only by leaving one nonzero scalar contribution per prime. That contribution is uniformly positive for a positive Schwartz smearing, so the infinite prime sum diverges. The candidate therefore cannot provide an honest trace-class Lefschetz formula.

### 6. FAILURE CLASS

**Nonzero Euler-index contribution forces trace divergence.**

Mechanism: for a prime-indexed direct sum, any fixed nonzero residual index contribution per block gives an infinite positive sum for a test function with hat f(0) > 0. This is a refinement of the infinite orbit multiplicity class: exact cancellation is compatible with trace summability only when it cancels the arithmetic contribution as well.

### 7. CONSTRAINT FOR THE NEXT CANDIDATE

The next candidate must cancel the divergent background in a trace-class way while retaining a nonzero arithmetic contribution whose size decays summably with p. A constant residual index per prime is impossible; any decay must arise from an intrinsic differential or representation-theoretic mechanism and must not be inserted as an arbitrary prime weight.



## Candidate 7: Prime-dependent twisted local systems

### 1. CONSTRUCTION

For each prime p, let L_p = log p and let E_p be the flat complex line bundle over C_p = R/L_p Z with holonomy exp(2 pi i/p). Sections satisfy f(x+L_p) = exp(2 pi i/p) f(x). The flow is translation with parallel transport in E_p. On the Fourier basis, the generator has frequencies 2 pi (k+1/p)/L_p for k in Z. Let H_7 be the direct sum of the L^2 section spaces over all primes, with the induced unitary flow. This uses an explicit prime-dependent local system rather than a norm weight or a hard frequency cutoff, and it uses no zero locations.

### 2. TEST (a): ORBIT LENGTHS AND CONTRIBUTION

The base orbit for p = 2 has primitive length log 2 and second iterate length 2 log 2. The base orbit for p = 3 has primitive length log 3 and second iterate length 2 log 3. Thus the geometric lengths remain correct and there is one base orbit per prime. However, parallel transport around the orbit multiplies the contribution by exp(2 pi i/p), and the m-th iterate by exp(2 pi i m/p). The Lefschetz contribution is therefore twisted rather than the required untwisted arithmetic contribution. Gate 1(a) fails in the full arithmetic sense, even though the geometric lengths pass.

### 3. TEST (b): TRACE-CLASS BEHAVIOR

For the Gaussian f(t) = exp(-t^2), with Fourier transform proportional to exp(-omega^2/4), the p-block trace contains the k = 0 term at frequency 2 pi/(p log p). Its magnitude is proportional to

exp(-pi^2/(p^2 (log p)^2)),

which tends to 1 as p tends to infinity. In particular, for all sufficiently large primes this term is bounded below by a fixed positive constant. Consequently the direct sum of smeared blocks has divergent trace norm, and the smeared operator is not trace class. Gate 1(b) fails.

### 4. TEST (c): INPUTS

Inputs are ordinary primes, circle lengths log p, the explicit holonomy exp(2 pi i/p), the translation flow with parallel transport, and the fixed Gaussian. No zeta-zero locations or zero ordinates are used. Gate 1(c) passes.

### 5. VERDICT

**FAIL(a) and FAIL(b).**

The twist changes the orbit weights, so it is not an exact arithmetic Lefschetz realization. It also does not create a uniform spectral gap: the shifted lowest frequency tends to zero as p grows, producing a positive nonsummable trace contribution from infinitely many primes.

### 6. FAILURE CLASS

**Vanishing spectral gap under intrinsic twists.**

Mechanism: a prime-dependent unitary local-system twist can be intrinsic and nontrivial, but if its phase approaches the trivial character as p grows, the lowest generator frequency approaches zero and trace divergence returns. The same twist also changes the required iterate coefficients.

### 7. CONSTRAINT FOR THE NEXT CANDIDATE

A successful candidate must have an intrinsic mechanism producing a uniformly nonzero or sufficiently growing spectral gap for large primes while preserving untwisted orbit coefficients exactly. Merely assigning prime-dependent holonomy is inadmissible unless its Lefschetz factors cancel or reproduce the required arithmetic weights.



## Candidate 8: Maximally gapped antiperiodic local systems

### 1. CONSTRUCTION

For each prime p, let C_p = R/(log p)Z and use the flat complex line bundle with holonomy -1. Its sections satisfy f(x+log p) = -f(x). Translation with parallel transport has generator frequencies 2 pi (k+1/2)/log p, k in Z. Take the direct sum over primes and smear the resulting unitary flow by Schwartz functions. ## Consolidation 10: no-go theorem for rank-one unitary flat twists

### Most frequent failure class

The recurring class is trace divergence from infinitely many prime-indexed orbit blocks. The strongest precisely provable subcase is the rank-one unitary flat-bundle class on the prime circles.

### Theorem (proved)

Let C_p = R/(log p)Z for each prime p. On C_p let E_p be any unitary flat complex line bundle, with holonomy exp(2 pi i theta_p), theta_p in R/Z. Let U_p be translation with parallel transport on L^2(C_p,E_p), and let U be the direct sum over all primes. For the Gaussian f(t)=exp(-t^2), the smeared operator U(f) is not trace class whenever every prime block is retained.

Proof. The generator frequencies on the p-block are 2 pi(k+theta_p)/log p, k in Z. Choose k_p nearest to -theta_p. Then |k_p+theta_p| <= 1/2, so the p-block contains an eigenvalue lambda_p with |lambda_p| <= pi/log p. The Gaussian Fourier multiplier is a positive constant multiple of exp(-lambda_p^2/4). Since log p tends to infinity, this multiplier tends to the positive constant hat f(0). Hence it is bounded below by hat f(0)/2 for all sufficiently large primes. The trace norm of the direct sum is at least the sum of these one-dimensional singular values, which diverges because there are infinitely many primes. Therefore U(f) is not trace class. QED.

The same class also cannot preserve the required untwisted arithmetic iterate coefficients unless every holonomy is trivial: the m-th orbit iterate acquires the factor exp(2 pi i m theta_p). Nontrivial holonomy changes the Lefschetz weights.

### Status

**PROVED for the stated rank-one unitary flat-twist class.** The proof uses only the circle length log p, unitarity of the holonomy, and the Gaussian smearing. It does not use positivity, Hodge theory, functional equations, or zero locations.

### Selection-bias audit

This is not a no-go theorem for all possible Frobenius constructions. It is genuinely forced within the explicitly stated class, because the nearest-integer bound for every unitary holonomy is universal. It does not rule out higher-rank complexes, non-unitary twisted cohomology, globally coupled prime orbits, or a geometry whose cohomological generator is not the circle translation generator. The broader infinite-orbit trace-divergence pattern remains only partial outside this class.

### Constraint for the next candidate

Candidate 11 must leave rank-one unitary flat bundles and must specify either a higher-rank/non-unitary twisted complex or a global coupling of primes. It must preserve the exact untwisted iterate coefficients and prove trace class for every Schwartz smearing without cutoff subtraction.

## Consolidation 20: No-go theorem for uncancelled logarithmic prime sectors

It does not include sign-changing global cancellations, non-unitary complexes with no positive residual, or a new geometric mechanism that changes the sector estimate.

### 2. NO-GO ARGUMENT

A direct elementary grouping also suffices: for each large j, primes in [exp(j^2), exp((j+1)^2)] contribute at least exp(-(j+1)), while the number of primes in that interval grows on the order of exp(j^2)/j^2. Therefore

sum_p a_p(h) >= c sum_p h(log p) = infinity.

Hence the smeared direct-sum operator cannot be trace class, and its positive trace cannot be defined by an honest cutoff-free sum. The conclusion is PROVED for the stated class.

This is genuinely forced within the stated class, not merely an artifact of candidate choice: the proof uses only the uniform positive lower bound and the logarithmic prime scale, so every object satisfying those hypotheses fails independently of how its sectors were constructed. It does not justify extrapolation to constructions that violate those hypotheses. The remaining live problem is therefore precise: find a global, non-positive or conditionally cancelling trace identity that retains coefficient one for each prime while producing an honest trace-class operator without subtraction.

### 5. CONSOLIDATION VERDICT

**PROVED NO-GO FOR THE STATED CLASS; NOT A UNIVERSAL NO-GO.**

No new failure class is needed. The theorem strengthens the existing class “Infinite orbit multiplicity / trace divergence” from partial to proved for its explicitly stated direct-sum/logarithmic-positive subclass, while the broader class remains partial.

### 6. CONSTRAINT FOR CANDIDATE 21

## Consolidation 50: Flow-level recurrence and monodromy dichotomy

**PROVED for the stated hyperbolic return-coupling class; PARTIAL globally.** The repeated obstruction is now a precise boundary: any successful Candidate 51 must leave the ordinary local-return Lefschetz framework or supply a new theorem showing how its trace avoids this dichotomy.

## Consolidation 60: Trace-class ideal obstruction for additive couplings

### 1. CLASS UNDER TEST

Let A_f be the smeared arithmetic operator contributed by the prime sectors for a fixed Weil-class test function f, and let B_f be a bounded global coupling whose smeared contribution is trace class. The proposed total operator is A_f + B_f. The coupling may be non-diagonal and may act across all prime sectors, but it is required to be a genuine trace-class perturbation rather than a cutoff or regularized subtraction.

### 2. PROVED OPERATOR NO-GO

The trace-class operators form a linear ideal in the bounded operators on a Hilbert space. If A_f + B_f were trace class and B_f were trace class, then A_f = (A_f + B_f) - B_f would also be trace class. But the corrected Gate-1 trace theorem gives a fixed Weil-class f for which the prime-sector arithmetic operator A_f is not trace class. Therefore no trace-class additive coupling B_f can make A_f + B_f trace class. This is a complete operator-ideal proof and is independent of the detailed matrix entries of B_f.

### 3. GEOMETRIC CONSEQUENCE

A trace-class additive coupling cannot repair the trace problem. A coupling strong enough to evade the ideal argument must itself fail to be trace class or must change the underlying arithmetic operator rather than add to it. Non-trace-class coupling was tested in Candidate 57 and produced undefined operator theory and mixed prime paths. Coupling that changes the generator also faces the recurrence dichotomy established in Consolidation 50.

### 4. IDENTITY-TERM PRIORITY AUDIT

A trace-class additive correction has finite trace and cannot cancel a divergent identity contribution in trace norm. A non-trace-class correction can cancel only through a conditional or regularized difference, forbidden by Gate 1(b). Thus no compatible identity mechanism exists within the additive-coupling class. The open class is a non-additive global realization in which the prime arithmetic operator is not a non-trace-class summand plus a correction.

### 5. SELECTION-BIAS AUDIT

This theorem is forced by the trace-class ideal property and the established non-trace-class arithmetic sector; it does not depend on choosing Hilbert, rank-one, or exponential kernels. It does not rule out replacing the entire operator by a new global trace-class construction, nor does it rule out non-Hilbert nuclear Fréchet characters, which are outside Gate 1(b).

### 6. CONSOLIDATION VERDICT

**PROVED NO-GO for additive trace-class couplings; PARTIAL globally.** The next candidate must not be an additive trace-class repair of the prime-sector operator. Candidate 61 must replace the non-trace-class arithmetic summand by a genuinely new global trace-class object while preserving the corrected orbit data.
